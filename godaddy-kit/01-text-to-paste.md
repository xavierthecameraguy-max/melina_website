# Onyx World Travel: text to paste into GoDaddy

For Xavier. Every word for the GoDaddy site, page by page, in the same order as the Sunny Passport design, top to bottom. The words are copied exactly from the demo site. The only changes: unknowns are marked [TO FILL: ...], "(required)" is taken out of form field names (you switch "Required" on instead), and the postcard's alt text and the gallery captions match the picture list in the images folder.


## How to use this file

- A **BOLD CAPITALS** line (like **HEADING** or **TEXT**) says what the thing is. Don't paste it. Paste the paragraph under it.
- **BUTTON** and **LINK** give the words on it, then "->" and where it must go.
- No fake buttons. Every button and link must go somewhere real. If you can't make one go to the right place, delete it. Never leave it pointing nowhere.
- "section" in a link means a spot lower down on a page. If GoDaddy can only link to a whole page (check in the editor), link to that page. If that page is the one the button is already on, delete the button.
- Phone links go to (914) 559-8159. Email links go to milena@onyxworldtravel.com.
- Every form: set "Send Message To" to milena@onyxworldtravel.com.
- [TO FILL: ...] means nobody knows this yet. Paste it as it is, so it's easy to spot and fill in later. Don't guess.
- (check in the editor) means the research couldn't confirm that GoDaddy can do this. Look before you rely on it.
- The words in parentheses after each section title are the section type from the build guide: Header, Button row, 3 columns, 2 columns, Trip cards, About / text + image, Text, Dark band, Photo gallery, Contact form.
