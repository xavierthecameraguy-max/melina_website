# Onyx World Travel: picture list

This folder has every picture for the Onyx World Travel website, ready to upload to GoDaddy.
The list below says where each picture goes and what to type as its **alt text**.

**What is alt text?** A short description of the picture. People who can't see the screen hear it read out loud, and Google reads it too. When GoDaddy shows a box for a photo's description or alt text, paste the alt text below into it. (Where that box is: check in the editor.)

Good to know:

- File names start with the page the picture goes on, then its order on that page, top to bottom.
- Photos (.jpg) are full size, at most 1600 pixels on the long side, with the hidden camera and location details removed.
- Drawings (.png) have a see-through background, so they sit nicely on any light section. Use a white, cream or pale tinted section behind them, never a dark one (the build guide calls these backgrounds L and T). The postcard picture goes on white or light cream only: its sun is pale yellow and would fade into a yellow or peach background.

- Keep a copy of this folder somewhere safe, outside GoDaddy.
